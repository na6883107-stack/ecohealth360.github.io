# ECO-HEALTH 360°

Arabic-first community health and environmental awareness website.

## Open the website

Once GitHub Pages is enabled, the site will be available at:

https://na6883107-stack.github.io/ecohealth360.github.io/

## Share with a QR code

Open the QR code and share page:

https://na6883107-stack.github.io/ecohealth360.github.io/share.html

The QR code points to the main website. To publish the site, go to **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. GitHub Pages may take a few minutes to publish.

## AI assistant

The assistant includes local educational fallback replies. The optional browser-side API-key field is a demo only: a key entered in a browser is not secret and should not be used for a public production website. For a real public AI integration, route requests through a secure backend and keep provider credentials on the server.
